# SKY Partner - Современный корпоративный сайт

Красивый современный сайт для компании SKY Partner с адаптивным дизайном и плавными анимациями.

## 🚀 Особенности

- ✅ Полностью адаптивный дизайн (мобильные устройства, планшеты, десктоп)
- ✅ Современный UI/UX дизайн с плавными анимациями
- ✅ Оптимизированная производительность
- ✅ Интерактивная форма обратной связи
- ✅ Интеграция с Google Maps
- ✅ Плавная прокрутка между секциями
- ✅ Мобильное меню

## 📁 Структура проекта

```
sky_partner/
├── index.html      # Основная HTML разметка
├── styles.css      # Стили и дизайн
├── script.js       # JavaScript функциональность
└── README.md       # Документация
```

## 📱 Блоки сайта

1. **Главный баннер** - полноэкранный баннер с градиентным фоном
2. **О компании** - информация о компании с изображением
3. **Наши принципы** - три карточки с принципами работы
4. **Наши направления** - сетка услуг (2x3)
5. **Почему выбирают нас** - статистика и преимущества
6. **Контакты** - форма обратной связи и карта

## 🛠️ Использование

1. Откройте `index.html` в браузере
2. Или используйте локальный сервер:
   ```bash
   # Python
   python -m http.server 8000
   
   # Node.js
   npx serve
   ```

## 📝 Настройка

### Изменение контента
- Откройте `index.html` и отредактируйте текстовый контент
- Измените изображения, добавив пути к файлам вместо placeholder'ов

### Изменение цветов
- Откройте `styles.css` и измените переменные в `:root`

### Настройка карты
- Замените URL в iframe Google Maps на нужный адрес
- Или используйте Google Maps API для более продвинутой интеграции
